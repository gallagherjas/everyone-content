# 账号与画像

账号是独立的内容运营空间，不等于抖音登录。首次启动创建空白「默认账号」；可改名或新增账号。关键词、参考博主、授权、规则、画像和结果分别维护，新账号不继承其他账号的资料。

## 初始化

Agent先看`AGENTS.md`顶部的一句话状态，状态缺失或不匹配时才请求`GET /api/initialization`。未完成时逐项引导填写账号定位、身份与人设、目标人群、目标与转化、内容策略、内容形式与制作条件、品牌与边界。全部七部分填写并保存生效后才完成；不适用的项目须由用户明确说明，定位和目标人群必须具体。

状态保存在SQLite的`account_initialization`，绑定当前画像SHA及章节契约版本。草稿不改变状态；画像生效或恢复时重算。状态会用一句话同步到`AGENTS.md`固定区域，只包含账号编号、完成状态及版本。已完成账号日常不再加载初始化Skill；新账号分别判断，不借用其他账号的完成状态。

画像初始化和指数登录分别记录。登录会话由用户在专用窗口扫码后自动私密保存；登录失效不会让完整画像重新变成未初始化。写作资料按需另外提供。

## 隔离

`accounts`保存配置及画像版本指针，`account_sources`保存关键词与参考博主，`account_works`关联本账号收录作品。API要求`x-everyone-content-account`并检查对象归属。切换账号时页面缓存清空，已发起请求仍绑定原账号。

授权范围为`account:<编号>`；同词查询不复用其他空间的授权结果。归档保留资料并阻止写入和定时采集，恢复后可继续使用。

## 画像版本

- Git引用：`refs/everyone-content/profiles/<account_id>`。
- 草稿：`runtime/drafts/<account_id>/`。
- 生效快照：`runtime/releases/<sha>/`。

保存草稿不改变当前版本；保存并生效后更新指针。版本操作不切工作分支或修改暂存区。恢复会生成新版本，旧版本保留。

## 已发布作品

「已发布」登记实际链接及北京时间。登记不触发网络请求；若指数收录同一作品，显示来源实际提供的指标。没有对应采集事实时，指标保持未知。

## 备份

完整备份包括SQLite、画像Git引用及对象、`runtime/`资料。使用SQLite backup或`VACUUM INTO`备份数据库；普通`git push`不包含画像专用引用，可另行导出：

```sh
git bundle create profiles.bundle '--glob=refs/everyone-content/profiles/*'
```

恢复需要数据库、画像Git对象及其材料文件，不应混用不同账号或不同安装的数据目录。
