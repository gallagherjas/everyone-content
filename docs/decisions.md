# 产品约束

- 项目名为「everyone-content」，面向多账号的本地内容采集与资料管理，唯一数据源为抖音指数。
- 新安装只创建空白默认账号及指数请求额度，没有预置行业、关键词、排除词、登录授权或内容资料。
- 用户自主选题，Agent只按需评估；评估输入为标题、目标群体、主要价值（一句话），只核对明确问题并根据真实资料建议更具体的表达，不预测爆款或编造结果。
- 首次使用由Agent主动引导初始化。全部七个画像章节填写并保存生效，是选题评估及写作的前置条件。状态按账号绑定生效版本，由程序计算；完成后用一句话将账号状态和版本写入AGENTS.md固定区域，日常直接据此判断，已完成时不加载初始化Skill；缺失或异常时才查轻量状态。
- 写作前须有用户本人的实质写作偏好或原文。Skill只说明用法、资料使用与引用，不内置通用写作套路。AI稿件不自行成为用户风格证据。
- 个人写作资料、评估结果和稿件当前在对话中交付，没有持久化登记入口，不承诺跨会话记忆或持续学习结果已保存。
- 账号配置、画像、授权及结果隔离；未知指标保留null，不把账号专属经验或词语变成全局默认。
- 发布登记不触发网络请求，指标只来自实际采集事实。
- 定时由本地工作台执行，默认关闭；不启动后台业务Agent或创作事件。原片下载、转写、抽帧与OCR不属于当前功能。
- 界面日期与时间按北京时间解释，数据库使用UTC。密钥与授权资料不提交或回显。
- 指数授权由用户在专用官方登录窗口扫码后自动私密保存，用户无需手工准备Cookie。登录状态与画像初始化分别记录，不读取已有浏览器个人资料，也不返回凭据给前端。
