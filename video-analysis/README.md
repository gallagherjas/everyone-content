# 视频截图

从抖音作品链接或本地视频按时间间隔提取截图，供查看画面和字幕。程序独立于采集流程，不写入工作台数据库。

## 使用

需要 Python 3.9 或更新版本和 FFmpeg 5.1 或更新版本，无需安装 Python 依赖。在项目根目录运行：

```sh
python3 video-analysis/extract.py 'https://www.douyin.com/video/视频编号' --output runtime/video-analysis/视频编号
```

也可把链接换成本地视频路径。抖音支持作品页、含 `modal_id` 的链接和短链。视频下载到临时目录，处理结束后删除；平台接口发生变化或限制访问时，可使用本地视频。抖音详情接口的请求方式参考 [short_videos](https://github.com/jiuhunwl/short_videos)。

默认每 0.5 秒抽一帧；可加 `--interval 2` 改成每 2 秒一帧。间隔越短，截图和处理量越大，持续时间短于间隔的字幕仍可能漏掉。输出目录必须是新目录，程序不会覆盖已有结果。

输出包括：

- `frames/`：按时间顺序排列的单帧图，最长宽度为 720 像素，不放大小图。
- `sheet-*.jpg`：4×4 预览拼图，从左到右、从上到下按时间排列。
- `index.json`：来源、抽帧间隔、每张单帧的目标时间和拼图文件名。目标时间从视频开始计算，实际抽到的是最接近该时间的画面。
