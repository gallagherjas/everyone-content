## 初始化顺序

按顺序，分步完成初始化，先完成账号与画像，再引导用户完成抖音指数采集配置。

1. 读取本地 `GET /api/initialization`，确定本次配置的账号。服务未启动时，按项目根目录 README 的「快速开始」处理。存在多个账号时，先确定目标账号。
2. 用户要求新建或列表为空时，按[账号与画像](../account-profile/SKILL.md)建号以及填写画像。账号名称尚未提供时一并询问。根据目标账号的 `setup.missing` 补齐缺项。
3. 完成账号与画像后提醒用户完成采集配置。读取[采集](../collection/SKILL.md)，扫码等待期间可以先处理其他缺项。
4. 重新读取初始化接口，按 `setup.complete` 汇报该账号的配置结果及剩余缺项，并按[采集](../collection/SKILL.md)说明授权或实采验证状态。用户要求试采时再启动一轮。

## 初始化完成

- 完成条件：至少存在一个账号，且完成账号画像（或者用户声称账号信息已经足够）、抖音指数授权、关键词和采集配置。`GET /api/initialization` 的 `setup.complete` 为 `true`。
- 完成后提供给用户前端地址，建议用户打开界面进行操作，并根据自己的需求调整采集配置。
