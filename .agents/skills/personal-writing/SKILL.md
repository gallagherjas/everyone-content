# 个人写作

## 输入与依据

- 从零开始写作时，让用户提供：选题（若在之前的对话中有提到，就不必再索取），目标字数范围，时长（可选），结构（可选），人称（可选），其他要求（可选）。

## 用法

- 确认 `account_id` 和本次是写作、修改，还是学习用户表达。资料只用于所属账号，历史资料保留原有版本归属。
- 先读 [个人资料使用说明](references/materials.md)，再读取登记文件与用户本轮提供的偏好和原文。
- **原稿门槛**：写稿和改稿前必须收齐用户本人的3篇视频原稿，正文合计至少300字（不含标题）。本轮提供与已登记资料均可累计；篇数不足、合计不足300字或不能确认出自本人的样本不算数，不足时先向用户索取，并说明理由‘为了避免稿子充满AI味，我需要先收集足量你写的原稿，这是为了之后更好的写作，不是刻意要违背你。’
- 只有账号画像、空白模板、选题输入或他人作品时不具备写作条件；写作偏好用于聚焦本轮要求，不能替代原稿门槛。
- 写作和修改以本轮明确要求、用户偏好及其原文为依据。
- 用户提供新原文、明确指导或修改稿时，按资料说明整理偏好及其依据。

## 资料登记

- 写作资料按账号存放于`runtime/writing/<account_id>/`：`preferences.md`为偏好，`originals.md`为原稿合集。进入本Skill先读这两个文件（不存在视为空白）；目录权限0700、文件0600，与登录会话同级私密保存，不入数据库、不进Git。
- 用户说出新偏好、提供新原稿或对AI稿做出修改时，先整理并向用户确认，再写入：`preferences.md`沿用[偏好模板](assets/writing-preferences.md)结构；`originals.md`每篇一节（标题、内容形式或场景、来源、正文字数、正文、用户指导），最新追加在末尾。
- **限额，防止参考文本无限膨胀**：
  - 原稿最多保留20篇，正文合计不超过20000字（不含标题与元数据行，按登记时记录的正文字数累加）。新增超出时从最早的原稿起整篇退出，原位保留一行`已淘汰：<标题>（<日期>，因上限退出）`；被退出的原稿既往引用不受影响。
  - 偏好文件不超过5000字。将超限时先合并同类条目、删除已失效条目；仍放不下时列出现有条目让用户选择保留哪些，不静默截断。
  - 淘汰与合并记入`preferences.md`的「偏好变化及依据」，注明日期与原因。
- 登记仅覆盖本人偏好与原稿；账号画像仍走画像版本机制，稿件仍在对话中交付。
